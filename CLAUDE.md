# Wehoop iOS

Women's basketball scores and stats (WNBA, NCAAWB, Unrivaled) on the wehoop-api backend.
M5 is a modular rebuild. **The spec is `docs/M5-PLAN.md`; read it before any slice.**
`Legacy/` is the old app, reference only: never build on it, never copy its key handling.

## Stack
- iOS 26.2+, iPhone and iPad, SwiftUI, Swift 6 language mode, Xcode 26.4.
- XcodeGen: `project.yml` → `Wehoop.xcodeproj` (generated, git-ignored; never edit it).
- `WehoopKit/`: local SwiftPM package (tools 6.2), one target per module.
- Backend: wehoop-api (Hono `/v1`, Supabase PostgREST + Realtime). supabase-swift arrives in S3, pinned exactly.

## Commands
```bash
swift test --package-path WehoopKit          # all package tests, macOS, no simulator
xcodegen generate                            # after any project.yml or App/ file add/remove
xcodebuild build -scheme Wehoop -destination 'platform=iOS Simulator,name=iPhone 17,OS=26.2' CODE_SIGNING_ALLOWED=NO -quiet
xcodebuild test  -scheme Wehoop -destination 'platform=iOS Simulator,name=iPhone 17,OS=26.2' -only-testing:AppTests CODE_SIGNING_ALLOWED=NO
scripts/check-deps.sh                        # module dependency rules
swiftlint lint --strict                      # Legacy/ is excluded
scripts/sync-contracts.sh [~/Projects/wehoop-api]   # regenerate WehoopKit/Sources/Contracts/Generated from the backend (records the commit in scripts/contracts-source); --check verifies
scripts/sync-goldens.sh [~/Projects/wehoop-api]     # recapture WehoopKit/Sources/TestSupport/Fixtures (golden JSON, S1) from the backend's seeded dev stack (pnpm seed:dev there); records the commit in scripts/goldens-source
```
CI (`.github/workflows/ci.yml`, macos-26) runs lint, check-deps, `swift test`, xcodegen and the app build.

## Module dependency rules (enforced by scripts/check-deps.sh)
```
App          → every Feature*, WehoopData, DesignSystem, Domain
Feature*     → Domain, DesignSystem        (never WehoopData, never another Feature)
WehoopData   → Domain, Contracts, LiveEngine, supabase-swift
LiveEngine   → Domain, Contracts           (no networking, no UI)
TestSupport  → Domain, Contracts, LiveEngine
Domain, Contracts, DesignSystem → nothing in the package
```
Features get data through a `Dependencies` struct of Domain protocols, wired in `App/CompositionRoot.swift`.
`Contracts` is generated by wehoop-api `pnpm gen:swift`; never edit it by hand.
The data module is `WehoopData` (not `Data`, which would clash with `Foundation.Data`).

## Concurrency rules
- Swift 6 mode, complete strict concurrency, zero warnings.
- `defaultIsolation(MainActor.self)` only for Feature*, DesignSystem and App
  (`SWIFT_DEFAULT_ACTOR_ISOLATION` in project.yml). Domain, Contracts, LiveEngine, WehoopData, TestSupport are nonisolated.
- Pure value types in main-actor modules that must work anywhere are marked `nonisolated`.
- No `@unchecked Sendable` or `nonisolated(unsafe)` without a comment saying why it is safe.
- View models: `@MainActor @Observable`, one `State` enum, `async` loads from `.task`/`.refreshable`;
  no fire-and-forget `Task {}` in view models. Engine state lives in actors or pure reducers.

## Testing rules
- Swift Testing (`import Testing`, `@Test`, `#expect`) everywhere; XCUITest only in `AppUITests`.
- Test behavior: reducer folds, sequencing, state transitions, decoding, contrast, routing.
  Never write not-nil or "view builds" tests.
- Engine modules must stay runnable under `swift test` on macOS (no UIKit in them).
- Fixtures come from the backend via TestSupport: `Golden` vends the JSON wehoop-api `pnpm golden` captured from its seeded dev stack (`Fixtures/manifest.json`; never hand-written, never edited); no live network in unit tests.

## Security non-negotiables
- The app ships **no provider key** (no Sportradar key, no API_KEY build setting, no xcconfig secrets).
  It talks only to wehoop-api and Supabase with the anon key and an anonymous session.
- **Never open, read, print, grep or copy `Legacy/Config.xcconfig`.** It holds a real key.
- Secrets come from environment variables only and never land in git, logs, evidence or devlogs.
- Base URLs are host-scoped; never attach credentials to requests for other hosts.

## Evidence rule
A slice is done only when its acceptance row in `docs/M5-PLAN.md` has evidence in
`devlog/evidence/M5.md`: the exact command, captured output (test counts from `swift test` /
`xcodebuild test`), and Simulator recordings or screenshots for UI rows.
Never claim "passes" without output. If something cannot run, write NOT RUN and why.

## Workflow
- Branch `m5-modular`; small commits; never push or merge without the owner asking.
- Each slice runs `/milestone` (implementer → reviewer → validator → devlog), agents in `.claude/agents/`.
- Strings go through `String(localized:)` / `LocalizedStringResource`.
